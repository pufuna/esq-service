# ESQ Service

Сервисная программа ООО «Элком» для преобразователей частоты и устройств плавного пуска ESQ (Modbus RTU / TCP, Windows).

**Установка:** скачайте и запустите [`releases/ESQ_Service_Setup.exe`](releases/ESQ_Service_Setup.exe) — он загрузит и установит последнюю версию. Дальше программа обновляется сама: «Связь и настройки» → «Обновление программы».

**Без интернета:** архив [`releases/`](releases/) `ESQ_ME800_Update_x.y.z.zip` распакуйте поверх папки программы.

Руководство пользователя — [`README_user.txt`](README_user.txt), в программе — клавиша F1.
